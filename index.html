Privacy Policy — ETX Toolbox

Last updated: November 26, 2026

ETX Toolbox is a modular browser extension with productivity, media, capture, privacy, developer, SEO, translation, and optional AI tools. This policy explains the data the extension handles, why it handles it, where it is stored, and when it is shared with third parties.

1. Our privacy commitment

  • No analytics or advertising trackers: ETX Toolbox does not operate user analytics, advertising trackers, or telemetry SDKs.
  • Local by default: Settings and tool data are stored in the browser on your device unless a feature requires a third-party service.
  • No sale of user data: We do not sell user data or use it for personalized, retargeted, or interest-based advertising.
  • Feature-related use only: We use page content, browsing context, and user-provided content only to provide the tool you enable or invoke.

2. Data handled and stored locally

The extension may store the following data locally in extension storage (browser.storage.local / browser.storage.session) or IndexedDB, depending on the tool:

  • Preferences such as language, enabled plugins, plugin order, favorites, recent tools, and side-panel state.
  • Tool settings and results, including color history, notes, custom CSS rules, bookmarks, timer state, reading statistics, and image or screenshot editing preferences.
  • User-created session recordings and related local metadata when you use Session Recorder.
  • Download and export choices needed to complete a user-requested download or export.
  • AI provider configuration, including an API key and selected model, if you choose to configure an AI provider.

ETX Toolbox does not operate a developer-controlled server for storing this local data.

3. Data shared with third parties

Some tools send only the content needed to deliver a feature you request:

  • Google Translate and text-to-speech: Selected or pasted text, the source/target language, and text-to-speech language are sent to Google Translate when you translate or listen to text. The Translate plugin does not require you to provide a Google account or API key.
  • Optional AI features: Text submitted to AI Summarizer or AI Writer — and captured regions if you explicitly switch OCR Lens to AI Vision mode — is sent directly to the AI provider you configure (such as OpenAI, Google Gemini, Anthropic, OpenRouter, or a custom OpenAI-compatible endpoint) using your own API key.
  • GitHub Repo Packer: When you choose to pack a GitHub repository, the extension requests public repository trees and file contents from api.github.com and raw.githubusercontent.com (using an optional personal access token only if you enter one).
  • TikTok media tools: When you request media inspection or download, the extension may contact public resolver services (tikwm.com, api.tiklydown.eu.org) with the requested TikTok video URL to locate the public media asset.
  • YouTube community tools: When enabled on YouTube, video IDs may be sent to returnyoutubedislikeapi.com (dislike counts) and sponsor.ajay.app (SponsorBlock segments) to display community data.
  • Dictionary & Currency Converter: When invoked, lookup words or currency requests are sent to dictionaryapi.dev, en.wiktionary.org, or open.er-api.com.
  • Citation Generator (DOI / ISBN lookup): When you look up a publication by DOI or ISBN, the extension queries api.crossref.org or openlibrary.org.
  • Password Health: Breach checks use api.pwnedpasswords.com with k-anonymity (only the first 5 characters of a SHA-1 hash are sent; your plaintext password never leaves your device).
  • Offline OCR model download: The compact Tesseract language model used by offline OCR Lens (about 0.5 MB) is fetched once on first use from the official tesseract-ocr/tessdata_fast repository on raw.githubusercontent.com, verified by SHA-256 hash, and cached locally in IndexedDB. This request contains no page content, screenshots, or recognized text, and you can remove the cached model anytime in OCR Lens settings.

The extension does not send page content, URLs, cookies, screenshots, recordings, or clipboard content to third parties unless it is necessary for a feature you explicitly invoke. Image conversion and resizing are performed locally in the browser.

4. Browser permissions

  • downloads — Save user-requested media, webpage images, screenshots, and exported text or files to the local device.
  • activeTab — Access the current page after a user action for tools such as screenshots, color sampling, page inspection, and media detection.
  • sidePanel — Display the ETX Toolbox dashboard in Chrome's Side Panel.
  • storage — Save local preferences, enabled plugin state, and tool data.
  • tabs and windows — Access the active tab's URL, title, and window context for page tools, screenshots, and extension navigation.
  • alarms — Schedule Pomodoro timers and reminders while the background worker is suspended.
  • scripting and <all_urls> host access — Run enabled content-based tools on webpages, such as Translate, Color Picker, image tools, page utilities, and media tools.
  • bookmarks — List bookmark folders and create a bookmark for the current page when requested.
  • cookies — Display and remove cookies for the current site when you use Cookie Cleaner or related privacy tools.
  • clipboardWrite — Copy user-requested output such as sampled colors, translations, generated text, screenshots, or extracted content.
  • contextMenus — Add supported right-click shortcuts, including translating selected text and media/page actions.
  • notifications — Notify you when Pomodoro focus sessions and breaks finish.
  • declarativeNetRequest — Apply scoped request-header rules for Translate's Google Translate/TTS requests, apply a custom User-Agent header when you enable the User-Agent Switcher, and optionally block ad or tracker requests when Ad Shield or Privacy Shield is enabled.
  • webNavigation — Re-apply active page tools (such as CSS Injector or Video Speed) cleanly on navigation events and collect local page-load metrics when inspected.
  • offscreen — Run local offline Tesseract WASM OCR, ZIP blob packaging, and timer chime audio outside the service worker.

5. Data retention and your choices

  • Local extension data remains on your device until you clear it through the relevant tool, clear browser extension data, or uninstall ETX Toolbox.
  • Files downloaded or exported by the extension are stored in the location you choose through Chrome's download behavior and can be deleted like other local files.
  • You can disable individual plugins at any time to stop their functionality.
  • Uninstalling the extension removes its extension storage. It does not delete files you previously downloaded or exported.

6. Security and policy compliance

Network requests made by ETX Toolbox for the features above use HTTPS where the relevant service supports it. ETX Toolbox uses user data only to provide or improve the user-facing features described in this policy and does not transfer it for advertising purposes.

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.
