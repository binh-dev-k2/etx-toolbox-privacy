Privacy Policy — ETX Toolbox v2.1.0

Last updated: July 25, 2026

ETX Toolbox is a modular browser extension providing a unified suite of 25 independent productivity, capture, e-commerce ad spy, and AI content utilities. This Privacy Policy outlines what information the extension stores locally, when network requests occur, and how browser permissions are strictly utilized.

1. Core Privacy Commitment

  • Zero Tracking: ETX Toolbox operates without any remote user analytics, advertising trackers, or telemetry SDKs.
  • Local First: All preferences, plugin states, downloaded media metadata, and tool configurations are stored locally on your device.
  • No Data Selling: We do not collect, transmit, or sell personal user data to third parties.
  • Explicit Action Only: Third-party API communication (such as AI summarization or TikTok media fetching) only occurs when explicitly initiated by the user.

2. Data Stored Locally on Your Device

The extension utilizes chrome.storage.local, localStorage, and IndexedDB strictly for essential functionality:

  • Extension Preferences & State: Enabled/disabled plugin states, custom display order, UI language selection (English/Vietnamese), and side panel target preferences.
  • E-Commerce & Ad Spy Cache: Download queue history for TikTok videos and original MP3 audio tracks saved locally to disk.
  • AI Content Studio Configuration: API keys (OpenAI, Gemini, OpenRouter), selected model profiles, and user-customized prompt presets.
  • Smart Capture & Session Recorder: Page screenshot annotations, region crop dimensions, and recorded DOM event timelines (rrweb format) stored in local IndexedDB.
  • Developer & Utility Settings: Saved notes, custom domain CSS rules, color picker HEX history, reading time statistics, and Pomodoro timer preferences.

3. Data Sent to Third-Party Services

ETX Toolbox performs network requests strictly to deliver requested features:

  • TikTok & E-Commerce Media Downloader: When saving TikTok video or audio posts without watermarks, the extension fetches public media assets directly from official CDN servers. No user credentials, session cookies, or personal tracking identifiers are transmitted.
  • AI Content Features: If you use AI Summarizer, Translator, or Copywriter features, text content explicitly selected or submitted by you is sent directly to your configured AI provider (e.g., OpenAI, Google Gemini, Anthropic, or OpenRouter) via secure HTTPS requests using your provided API key.
  • Remote Image Processing: Features like Image Converter process images locally inside your browser using HTML5 Canvas APIs without uploading files to remote conversion servers.

4. How Browser Permissions Are Used

  • downloads — Save TikTok videos, audio tracks, webpage images, captured screenshots, and extracted text files directly to your device's Downloads folder.
  • activeTab — Capture visible tab viewports for screenshots, sample pixel color values for Color Picker, and inspect page DOM for media detection.
  • sidePanel — Render the main ETX Toolbox dashboard in Chrome's native side panel interface.
  • storage — Store user preferences, plugin states, color history, and custom tool rules locally.
  • tabs — Read current tab titles and URLs for Page Insight reading time calculation and screenshot stitching.
  • scripting — Inject lightweight content scripts on open web pages to enable interactive tools like Floating AI Text Selection and Color Picker.
  • bookmarks — Display bookmark folder trees and allow one-click page bookmarking.
  • cookies — Display active domain cookies and permit users to clear tracking cookies for privacy control.
  • clipboardWrite — Copy captured screenshots, sampled colors, AI summary text, and extracted content to your system clipboard.
  • contextMenus — Add right-click shortcuts for downloading images, extracting text, and generating AI summaries from selected text.
  • notifications — Send desktop notifications when Pomodoro timer focus or break intervals end.
  • <all_urls> — Enable page-level content scripts to run across websites requested by the user.

5. Data Retention & User Control

  • All extension data stored in chrome.storage.local or IndexedDB remains on your device until manually cleared or until the extension is uninstalled.
  • You can clear saved notes, screenshot history, color palettes, and session recordings at any time directly within the extension options menu.
  • Uninstalling ETX Toolbox automatically removes all local storage associated with the extension.
